# Octocaris 0.1.0

Octocaris 是把 Octos 重写为 Rust + WebView2 的轻量动态壁纸运行器。
这里只保留**一个**发布：每次更新都覆盖同名的便携包，下载链接永远不变。

## 下载

`Octocaris-win-x64-portable.zip` —— Windows 10 1809+ / 11，x64，绿色版：

1. 解压到本地磁盘（不要在压缩包里或网络共享上直接运行）。
2. 双击 `octocaris.exe`；所有数据都在旁边的 `data\` 里，整个文件夹可以拷走。
3. 缺少 WebView2 Runtime 时，运行包内的 `MicrosoftEdgeWebview2Setup.exe`（需联网）。
4. exe 未签名，SmartScreen 提示时选“更多信息 → 仍要运行”。
5. 程序图标（章鱼）已经嵌在 exe 里，不需要额外的 `.ico` 文件。

## 包含的功能

- **壁纸库**：每页 24 张、右侧轮换队列、详情抽屉、Ctrl 多选、拖拽/Alt+↑↓ 排序
- **每屏独立**：每个显示器单独选壁纸，各自记住壁纸面板里按屏幕调好的位置/缩放
- **混合 DPI**：按显示器取 DPI，100%–400% 混合缩放、热插拔都能正确重建
- **社区**：应用内浏览 264 张在线壁纸，支持搜索、动图预览、下载安装、更新、取消
- **Web 壁纸默认参数**：首次加载时写入 BGM 0、关闭视线追踪/鼠标轨迹、贴图 4k；
  之后你在壁纸面板里改的值会保留，位置和缩放永远不受默认值影响
- **恢复默认参数**：壁纸详情抽屉里一键重新写入默认值（每块屏独立）
- 整体静音、开机启动隐藏到托盘、轻量模式、帧率上限、全屏暂停
- 支持 L2D / Spine、图片、普通网页壁纸；旧 mod 目录和 zip 都能直接用

## 这一版的内容（2026-10-28）

- 社区页：搜索、分页、GIF 预览、详情抽屉、下载/安装/更新/取消
- Web 壁纸默认参数：老式 `fileNames` 包和新式 `SettingModel` 包都覆盖
- 壁纸详情里的卸载确认改成警示卡片；社区分页与壁纸库样式统一
- 修复：首次启动 / 库切换时默认值不注入；原地切换壁纸时不更新注入脚本
- 默认值不再写入 `position` / `scale`，按屏幕微调不会被覆盖

## 已知限制

- 测试版，仅 x64 便携包，未签名、无安装器。
- 老式 web 壁纸的默认参数只覆盖 BGM / 视线追踪 / 鼠标轨迹 / 贴图分辨率四项。
- 媒体/音频 API 仍为协议桩。
