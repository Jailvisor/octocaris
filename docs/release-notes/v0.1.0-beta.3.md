# Octocaris 0.1.0 Beta 3

第三个测试版。本次加入**应用内社区**：不用离开程序，就能浏览、下载、安装和更新在线壁纸。
社区目录来自 `Jailvisor/octocaris-community`，目前已有 80+ 项。

## 新增：社区

- 顶栏“社区”页：搜索、分页（每页 24）、GIF 动图预览、详情抽屉。
- 详情里有包内文件清单、大小、SHA-256、Wallpaper Engine 来源链接，可直接在浏览器打开项目页。
- 下载 → 校验大小与 SHA-256 → 后台解压 → 安全替换目录；中途可取消。
- 下载中显示进度；断网/超时/源站错误会以可翻译的错误码提示，已下载的临时文件下次启动自动清理。
- 已安装的条目显示“已安装”，远端版本更高时显示“更新”；版本不变时不会重复下载。
- 替换失败会回滚到旧版本；进程被杀导致的半成品会在下次启动时自动恢复。
- 使用 WinHTTP，走系统代理 / PAC，可在 `preferences.json` 里改 `communityIndexUrl`。
- 命令行：`octocaris community install <folder>`、`community refresh`、`community cancel`。

## 新增：Web 壁纸默认参数

- 老式 “Vue + loadJson” 壁纸可以在 mod 根目录放 `octos-defaults.json`，
  在页面脚本运行**之前**写入 `localStorage` 默认值（BGM 音量、视线追踪等）。
- `mode: "fill"`（默认）只补用户还没改过的键；`mode: "force"` 每次加载都覆盖。
- 新式带 `SettingModel` 的包不处理，避免与包自身的设置结构冲突。

## 其他

- 安装 zip 时会保留包内的 `octos-defaults.json`，并保留 `octos-community.json` 标记里的真实目录名。
- 新增 `validate_folder_name` 校验，拒绝带路径分隔符或 `..` 的社区目录名。

## Beta 2 已有内容

- 按显示器取 DPI，混合 DPI / 双屏渲染比例修复；运行中修改缩放自动重建。
- 壁纸库重构：右侧轮换队列、详情抽屉、每页 24、Ctrl 多选。
- 整体静音、Win10 桌面图标 WorkerW 修复、开机启动隐藏到托盘。
- `octocaris.exe`、图标内嵌、静态 VC++ 运行库、便携 data 目录。

## 安装

1. 解压 zip 到本地磁盘，双击 `octocaris.exe`。
2. 缺少 WebView2 Runtime 时运行包内 `MicrosoftEdgeWebview2Setup.exe`（需联网）。
3. 未签名 exe，SmartScreen 提示时选择“更多信息 → 仍要运行”。
4. 首次打开“社区”页需要联网（GitHub raw / Release 下载）。
