# Octocaris 0.1.0 Beta 1

这是 Octocaris 的第一个测试版。Windows 10 / 11 x64 便携版，解压即用。

## 本次内容

- **壁纸库前端重构**：每页 24 个、卡片放大；右侧常驻轮换队列栏（可折叠），队列自身决定轮换顺序；卡片 hover `+` 加入、序号徽标移出；Ctrl+点击多选 + 底部操作条；详情改为右侧抽屉。
- **清晰度**：壁纸页按物理像素渲染（`zoom = 96/dpi`），200% 缩放下 L2D 不再发软，与 Wallpaper Engine 一致。
- **整体静音**：设置页和托盘菜单均可切换，对所有壁纸页生效。
- **Win10 桌面图标**：修复「显示桌面图标」报 `SHELLDLL_DefView is not available`（挂载后 DefView 位于 WorkerW 下）。
- **开机启动隐藏到托盘**：注册 `--startup`，登录后只驻留托盘，不弹主窗口；再次启动显示已有窗口。
- **打包**：二进制更名为 `octocaris.exe`，图标嵌入 PE；VC++ 运行库静态链接。
- 其他：壁纸库分页、缩略图、拖拽/zip/图片导入、每显示器独立壁纸、帧率上限、全屏暂停、中英双语。

## 安装

1. 解压 zip 到本地磁盘（不要直接在压缩包或网络共享里运行）。
2. 双击 `octocaris.exe`。
3. 如果提示缺少 WebView2 Runtime，运行包内 `MicrosoftEdgeWebview2Setup.exe`（需联网），或安装 Evergreen Standalone Installer。
4. 未签名 exe，SmartScreen 提示时点「更多信息」→「仍要运行」。

数据保存在包内 `data\`（便携模式）；删除 `data\` 即恢复初始状态。

## 已知限制

- 测试版，仅提供 x64 便携包；尚未签名、未做安装器。
- Win10 桌面图标修复请在 Win10 实机验证后反馈日志。
- 媒体/音频 API 仍为协议桩，L2D 自带音频可播放/静音，但 GSMTC 媒体控制未实现。
