# Octocaris 0.1.0 Beta 2

第二个测试版。主要修复双屏 / 混合 DPI 下的渲染比例问题。

## 本次修复

- **按显示器取 DPI**：壁纸子窗口的 `GetDpiForWindow` 会返回主屏 DPI，改用 `GetDpiForMonitor`。
  - 100% → zoom 1.0
  - 150% → zoom 0.6667
  - 175% → zoom 0.5714
  - 200% → zoom 0.5
  - 页面视口始终等于物理像素，`devicePixelRatio = 1`。
- **运行中修改缩放**：watchdog 检测到某块屏 DPI 变化时重建该屏的壁纸 controller，日志 `wallpaper DPI changed ... recreating WebView`。
- 双屏实测：热插拔、每屏独立壁纸、队列顺序 `1/4→2/4→3/4→4/4→1/4`、下一张、随机模式不连续重复、副屏鼠标坐标映射均通过。

## Beta 1 已有内容

- 壁纸库重构：右侧轮换队列、详情抽屉、每页 24、Ctrl 多选
- 整体静音、Win10 桌面图标 WorkerW 修复、开机启动隐藏到托盘
- `octocaris.exe`、图标内嵌、静态 VC++ 运行库、便携 data 目录

## 安装

1. 解压 zip 到本地磁盘，双击 `octocaris.exe`。
2. 缺少 WebView2 Runtime 时运行包内 `MicrosoftEdgeWebview2Setup.exe`（需联网）。
3. 未签名 exe，SmartScreen 提示时选择“更多信息 → 仍要运行”。
4. 支持每屏不同缩放（100%–400%），建议先设好缩放再启动；运行中修改也会自动重建。
