# UX Review Checklist

用于人工审查 Octos 的交互与使用体验。当前 M2 完成、M3 进行中；UI 仍是 M1 shell。

## 推荐时机

| 时机 | 审查范围 |
|---|---|
| 现在（M2 完成） | 桌面交互 + App 外壳；轻量、只定方向 |
| M4 完成 | Library/安装/选项/显示器选择的完整流程 |
| M5 完成 | 稳定性、性能/省电、文案、空态/错误态、键盘/可访问性最终验收 |

## A. 桌面交互（现在可审）

- [ ] 壁纸在桌面图标下方，图标始终可见。
- [ ] 桌面图标可正常点击/框选。
- [ ] 桌面右键出现“查看/排序/刷新/新建/显示设置/个性化”等菜单。
- [ ] 壁纸页面上的按钮/交互可点击（gradient 的 “Click me” 会写日志）。
- [ ] 壁纸不会抢焦点，不出现在 Alt+Tab/任务栏。
- [ ] 打开全屏游戏/视频时壁纸暂停，退出后恢复。
- [ ] 重启 Explorer 后壁纸、图标、托盘自动恢复。
- [ ] 壁纸 Clear 后桌面干净；Show 后恢复。
- [ ] Settings 的 “Show desktop icons” 开关能隐藏/恢复图标，且不覆盖 Windows 用户设置。

## B. App 外壳（现在可审）

- [ ] 主窗口大小/位置是否合适（当前 1100×720 逻辑像素，200% 缩放下较大）。
- [ ] 标题栏/最小化/最大化/关闭行为是否符合 Windows 习惯。
- [ ] 关闭到托盘是否明确；托盘图标/菜单是否容易发现。
- [ ] 第二实例是否唤起已有窗口，而不是出现两个实例。
- [ ] 日志/错误提示是否可发现（当前主要写文件，没有 UI 提示）。
- [ ] Library 空态文案是否清楚说明当前阶段能力。

## C. 暂不评价（等 M4/M5）

- Library 卡片、安装 zip、按显示器选择、选项表单。
- Explore/社区、搜索、下载。
- 多语言、主题、快捷键、可访问性细节。
- 安装包/自动更新。

## D. 反馈记录建议

按“场景 → 期望 → 实际 → 严重度（阻塞/体验/细节）”记录，附截图或日志时间点；桌面层级问题请同时附 `scripts/verify-desktop.ps1` 输出。
